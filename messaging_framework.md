# Messaging Framework

## Core Message

Communicate the value of the offering clearly and responsibly, with the audience's needs at the center.

## Messaging Pillars

### 1. Value

Explain how the offering can help the target audience.

### 2. Clarity

Communicate the main message using simple, direct language.

### 3. Trust

Use accurate, transparent, and supportable messaging.

### 4. Relevance

Adapt the message to the audience, platform, and campaign objective.

### 5. Action

Provide a clear and appropriate next step or call to action.

## Audience Messaging

Before generating campaign content, understand:

- Who the target audience is.
- What problem, need, or interest the audience has.
- What value the campaign communicates.
- What action the audience should take.

## Campaign Goal

The campaign message should align with the stated campaign goal.

Examples of campaign goals:

- Awareness
- Engagement
- Education
- Lead generation
- Product promotion
- Website traffic
- Community building

Do not assume the campaign goal when the user has not provided one.

## Platform Adaptation

Content should be adapted to the requested platform.

Consider:

- Platform format
- Expected content length
- Audience behavior
- Appropriate tone
- Call-to-action style

Do not use the same format automatically across every platform.

## CTA Framework

Calls to action should be:

- Clear
- Relevant
- Appropriate for the campaign goal
- Consistent with the brand tone

Examples:

- Learn more
- Explore the details
- Get started
- Visit our website
- Contact us
- Sign up

## Message Structure

The primary content-generation structure is:

**Headline → Body Copy → CTA**

The headline should communicate the main idea.

The body copy should explain the relevant value or message.

The CTA should provide an appropriate next step.

## Consistency Rules

Every message should maintain consistency across:

- Brand voice
- Brand values
- Audience
- Campaign goal
- Platform
- Tone
- CTA

## Responsible Messaging

Do not:

- Invent product benefits.
- Make unsupported claims.
- Guarantee results without evidence.
- Use misleading urgency.
- Use deceptive comparisons.
- Make claims that could create legal or compliance risks.

If required information is missing, ask a clarification question before generating the content.
