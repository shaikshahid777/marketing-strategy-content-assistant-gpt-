## ✨ Project Overview

**Marketing Strategy & Content Assistant GPT** is a Custom GPT designed to support marketing content creation while maintaining brand voice, messaging consistency, platform relevance, and responsible communication.

## 🎯 Core Capabilities

- 🔎 Required-input validation
- 🎯 Campaign-goal alignment
- 👥 Target-audience awareness
- 📱 Platform-specific adaptation
- 🗣️ Brand voice and tone consistency
- 🛡️ Brand-safety guardrails
- 🚫 Unsupported-claim protection
- 🔄 Multiple content variants
- 📣 Consistent **Headline → Body Copy → CTA** structure

## 🧠 How It Works

Campaign Request → Required Input Validation → Brand Knowledge Review → Platform & Tone Adaptation → Safety Check → Headline → Body Copy → CTA → Final Quality Check

## 📚 Knowledge Base

| File | Purpose |
|---|---|
| `brand_guidelines.md` | Brand purpose, values, voice, tone, writing principles, and safety rules |
| `messaging_framework.md` | Messaging pillars, audience, campaign goals, platform adaptation, and CTA guidance |
| `campaign_examples.md` | Example campaigns and preferred messaging structure |

## ⚙️ Instruction Layer

`instruction_block.md` defines the assistant role, required-input validation, knowledge grounding, platform adaptation, brand-safety rules, unsupported-claim handling, over-promotional correction, unsafe competitor wording handling, multiple variants, and final quality checks.

## 🛡️ Brand Safety

The assistant avoids unsupported guarantees, invented statistics, misleading promises, unsupported superiority claims, deceptive comparisons, unverified competitor accusations, manipulative urgency, and unsupported legal/compliance-sensitive claims.

When unsafe wording is requested, it preserves the legitimate marketing objective where possible while providing a safer alternative.
